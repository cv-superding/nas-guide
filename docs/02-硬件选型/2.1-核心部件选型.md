# 2.1 CPU、内存、网口，到底怎么挑

> 📌 先读：[1.2 它能做什么](../../docs/01-认识NAS/1.2-NAS能做什么.md) · ⏱ 大约 12 分钟

## 先记住一个前提

配 NAS 和配游戏电脑，思路完全不一样。

游戏电脑看CPU 和显卡跑分，NAS 更多时候在"闲着"——它要的是长期稳定、低功耗、能装下多块硬盘。所以这一节讲配置，核心不是"哪个最强"，而是**"哪个刚好够你用"**。

## CPU：看你的用途

| 你主要干嘛 | 需要什么样的 CPU |
| --- | --- |
| 存照片、备份 | 低功耗双核/四核，够用 |
| 看 4K 电影 | 带硬件编解码的核显（如 Intel Quick Sync） |
| 跑 Docker 多服务 | 四核以上 |
| 跑虚拟机 | 多核多线程 |
| 跑本地 AI | 大内存 + 可选显卡，CPU 反而次要 |

> 💡 最常见的"性能浪费"是买顶级 CPU 只存照片；最常见的"后悔"是没核显却要转码 4K。先想清楚用途。

x86（Intel/AMD）生态最广，Docker、虚拟机、AI 都支持好，是本指南主力推荐。ARM（树莓派）功耗极低，但性能和软件生态受限，见 [3.7](../../docs/03-平台横评与选型/3.7-树莓派与软路由.md)。

## 内存：宁多勿少

| 场景 | 建议 |
| --- | --- |
| 纯存储 | 2～4 GB |
| Docker + 影音 | 8 GB（主流甜点） |
| 虚拟机 / ZFS | 16 GB 起 |
| 本地 AI | 16～64 GB，看模型大小 |

> ⚠️ ZFS 比较吃内存，能用 ECC 更稳妥。家用不必强求 ECC，但请选可靠品牌、留余量。

## 主板、网口这些

- **SATA 口数量**决定能接几块盘，不够可用 HBA 卡扩展
- **M.2 插槽**适合做系统盘或高速缓存
- **网口**至少千兆，预算允许上 2.5G 更从容

> 💡 很多人忽略网口：内网速度的瓶颈常常不是硬盘，而是网络。一个 2.5G 网口 + 支持 2.5G 的交换机，传大文件的体验提升明显。见 [6.1](../../docs/06-网络与远程访问/6.1-局域网基础.md)。

## 电源、机箱、UPS

- 电源选可靠品牌，额定功率留余量——多盘启动瞬间电流不小
- 机箱注意风道和硬盘减震，噪音很多来自共振
- UPS（不间断电源）能在断电时安全关机，对数据有意义

## 写在最后

CPU 看用途、内存宁多勿少、网口尽量快、电源机箱别省钱。记住：硬盘和网络往往比 CPU 更影响体验。

## 动手试试

1. 按你的用途写下 CPU、内存、网口三项的初步要求。
2. 查一下你现有电脑的 CPU 带不带硬件转码（搜"型号 + Quick Sync"）。
