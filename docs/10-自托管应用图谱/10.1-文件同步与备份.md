# 10.1 文件、同步与备份类

> 这一节逛什么：除了第 7 章的 Nextcloud，还有哪些"管文件"的选择

## 先分清三类

"管文件"其实有三种不同需求，别混在一起：

| 类型 | 解决什么 | 代表 |
| --- | --- | --- |
| 网盘/文件浏览器 | 网页上管理、分享文件 | Nextcloud、Seafile、filebrowser |
| 多设备同步 | 让几台机器文件一致 | Syncthing、Resilio Sync |
| 备份 | 能回到过去的历史版本 | restic、borg、Duplicati |

> ⚠️ 再强调一次：**同步 ≠ 备份**。前两类都不算真正的备份，见 [5.4](../05-存储与数据保护/5.4-备份3-2-1原则.md)。

## 网盘与文件浏览

| 应用 | 特点 | 适合 |
| --- | --- | --- |
| **Nextcloud** | 功能最全：文件、日历、文档、协作 | 想要"全套网盘"（已在 7.4 讲） |
| **Seafile** | 专注文件同步，性能较好 | 团队文件协作 |
| **filebrowser** | 极简的网页文件管理器 | 只想快速浏览/上传文件 |
| **Filestash** | 支持多种后端（SMB/FTP/S3）的网页前端 | 已有存储，只缺一个访问界面 |

> 💡 很多人装了 Nextcloud 才发现"我其实只是想在网页上看看文件"——那种情况 filebrowser 就够了，轻得多。

## 同步工具

| 应用 | 特点 |
| --- | --- |
| **Syncthing** | 去中心化、点对点、跨平台，已在 7.3 讲 |
| **Resilio Sync** | 基于 BT 协议，速度快，部分功能收费 |

## 备份工具

| 应用 | 特点 | 适合 |
| --- | --- | --- |
| **restic** | 加密、去重、增量，命令行强大 | 脚本化自动备份（本指南示例用它） |
| **borgbackup** | 类似 restic，去重效率高 | 大容量备份 |
| **Duplicati** | 有 Web 界面，支持云存储 | 想要图形界面的备份 |
| **Kopia** |  modern，有 Web UI，支持快照策略 | 想兼顾易用与强大 |

> 💡 不管用哪个，记得**定期做恢复演练**。没验证过的备份等于没有备份。

## 图床与文件分享

| 应用 | 特点 |
| --- | --- |
| **Chevereto** | 功能完整的图片托管 |
| **Lsky Pro（兰空图床）** | 国产、界面友好、支持多种存储后端 |
| **Transfer.sh / Wormhole** | 临时文件分享，设有效期自动删除 |

> ⚠️ 图床如果暴露公网，注意防盗链和内容合规。

## 来自清单项目的提示

[awesome-selfhosted](https://github.com/awesome-selfhosted/awesome-selfhosted) 在文件存储这一分类下列了几十个项目，并用标签标注了技术栈（Docker / PHP / Go 等）和许可证。挑的时候可以留意两点：**许可证是不是你能接受的**，以及**项目是否还在活跃维护**。

## 写在最后

网盘、同步、备份是三件事。想清楚你要哪一样，再从上面对号入座。

## 动手试试

1. 写下你现在的文件管理方式，看它属于哪一类。
2. 如果你只有"网页看文件"的需求，试试 filebrowser 而不是 Nextcloud。
