# 10.3 效率、协作与知识类

> 这一节逛什么：把 NAS 变成私人办公室

## 笔记与知识库

| 应用 | 特点 | 适合 |
| --- | --- | --- |
| **Joplin** | 开源笔记，支持端到端加密，可同步到 NAS | 记笔记 ✅ |
| **Obsidian + 同步** | 本地 Markdown 笔记，配合 Syncthing/Nextcloud | 双链笔记爱好者 |
| **Trilium Notes** | 功能强大的层级笔记 | 知识管理深度用户 |
| **Logseq** | 大纲式笔记，本地优先 | 块引用爱好者 |
| **Anytype** | 现代知识管理工具 | 想要新范式 |

> 💡 很多人问" NAS 上跑哪个笔记"。答案取决于你用什么客户端：Joplin 自带同步服务器最省事；Obsidian 用户直接用 Syncthing 同步文件夹即可，不必额外装服务。

## 协作与看板

| 应用 | 特点 |
| --- | --- |
| **Focalboard** | 看板工具（Notion 类似） |
| **AppFlowy** | 开源替代品，协作文档 |
| **Vikunja** | 任务管理，看板 + 清单 |
| **Kanboard** | 轻量看板 |
| **Gitea** | 自建 Git 服务，也能当轻量协作平台 |

## 密码管理

| 应用 | 特点 |
| --- | --- |
| **Vaultwarden** | Bitwarden 兼容的轻量服务（已在 7.4 提） |
| **KeePass + 同步** | 本地密码库 + Syncthing 同步 |

> ⚠️ 密码库是最高敏感的服务：HTTPS + 强主密码 + 2FA + 备份，一个都不能少。丢了数据 = 丢所有密码。

## 文档与 PDF

| 应用 | 特点 |
| --- | --- |
| **Paperless-ngx** | 文档扫描、OCR、归档、检索，神器级 |
| **Stirling-PDF** | PDF 工具箱（合并、拆分、转换） |
| **Tesseract** | OCR 引擎（常作为其他工具的底层） |

> 💡 Paperless-ngx 特别适合"纸质文件太多"的家庭：扫描进来自动 OCR，以后搜索关键字就能找到。

## 日历、联系人、邮件

| 应用 | 特点 |
| --- | --- |
| **Baikal** | 轻量 CalDAV/CardDAV 服务器 |
| **Nextcloud 的日历/联系人** | 如果你已经装了 Nextcloud，直接用它的 |
| **Mailcow / iRedMail** | 自建邮件服务器（重，新手慎入） |

> ⚠️ 自建邮件服务器门槛高：需要域名、DNS 记录（SPF/DKIM/DMARC）、IP 信誉，普通家庭用户不推荐从这入手。

## 来自清单项目的提示

[mikeroyal/Self-Hosting-Guide](https://github.com/mikeroyal/Self-Hosting-Guide) 把这类工具按"生产力""协作"分门别类，并给每个条目标注了技术栈和官网。它特别强调一点：**先想清楚工作流再选工具**——不然装了也是吃灰。

## 写在最后

效率工具的选择，核心是"和你现有的习惯匹配"。用 Obsidian 就别硬上 Joplin，用 Nextcloud 就别再装 Baikal。少即是多。
