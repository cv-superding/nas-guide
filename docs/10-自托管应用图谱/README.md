# 10 自托管应用图谱：这台机器还能装什么

> ⏱ 大约 40 分钟 · 难度 ⭐⭐ · 当成"地图"来逛，不用记

## 这一章为什么存在

第 7 章我们装了影音、下载、相册、AI 这几样最常见的应用。

但 NAS 能跑的东西远不止这些。很多人装完几个应用后，会冒出下一个问题：**"还有啥好玩的？"**

这一章就是回答这个问题的。它是一张地图，按场景把值得了解的自托管应用分门别类列出来。你不需要全装——事实上**千万别全装**——只要逛一遍，知道"原来这个也能自己搭"，等哪天真有需求时，回来按图索骥就行。

> 💡 本章的思路参考了 [awesome-selfhosted](https://github.com/awesome-selfhosted/awesome-selfhosted) 与 [mikeroyal/Self-Hosting-Guide](https://github.com/mikeroyal/Self-Hosting-Guide) 这类"精选清单"项目的组织方式——按场景分类、每个条目说清用途。完整致谢见 [CREDITS](../../CREDITS.md)。

## 先记住三条

1. **地图不是购物清单**：逛归逛，只装你真会用的。收集式部署是吃灰的开始。
2. **每个应用都要问三句**：它解决我的什么问题？数据存哪儿？要不要暴露到公网？
3. **新应用先测试**：装在一个隔离环境里试几天，确认有用再正式用。

## 写在最后

自托管的乐趣，不在于装了多少，而在于"我需要什么，就能自己搭出来"的那份自由。把这张图存着，慢慢逛。
