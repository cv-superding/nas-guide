> 定位：极简轻量、旧机改造与容器入门的首选

## 这位选手什么脾气

CasaOS 是那种"随和、好相处"的朋友——不挑硬件，旧电脑、迷你主机、树莓派都能跑，装好就能用。

它的哲学是"简单就好"：只做文件管理和容器这两件事，但做得清爽利落。代价是，复杂的数据保护得你自己补。

## 基本信息

CasaOS 是一个基于 Debian 的开源轻量 NAS 系统，主打"简单好用"和"应用商店式体验"。它常装在旧电脑、迷你主机或树莓派上，用于快速搭建个人云与 Docker 服务。

| 项目 | 说明 |
| --- | --- |
| 基础 | Debian Linux |
| 文件系统 | ext4 / Btrfs（依安装方式） |
| Docker | 核心能力，App Store 一键安装 |
| 中文支持 | 良好 |
| 硬件 | x86 与 ARM 均可 |

## 它的长处

1. **安装极简**：一条命令即可安装（在干净的 Linux 上）。
2. **界面清爽**：现代化 UI，新手友好。
3. **应用商店**：常见自托管服务一键部署。
4. **旧机救星**：低配置也能流畅运行。
5. **开放**：本质是 Linux，可随时安装其他工具。

## 它的短板

- **存储管理较弱**：RAID、快照等高级存储功能不如群晖/TrueNAS。
- **不适合关键数据**：缺少企业级数据保护机制，需自行加强备份。
- **功能相对简单**：进阶玩法需要自己用命令行补足。

## 适合这样的人

- 旧电脑/迷你主机改造，先体验 NAS
- 主要跑 Docker 服务、轻量文件共享
- 喜欢简洁界面、不想被复杂功能淹没

## 这些人再想想

- 追求完善 RAID 与数据保护的纯存储场景
- 需要企业级稳定性

## 安装方式概览

```bash
# 在干净的 Debian/Ubuntu 系统上（示例，请以官方最新脚本为准）
curl -fsSL https://get.casaos.io | sudo bash
```

> ⚠️ 安装脚本会修改系统配置，请在全新系统上使用，并先阅读官方文档。本指南不提供脚本托管。
