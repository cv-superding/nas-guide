# 3.8 OpenMediaVault：Debian 底盘的"极简实干家"

> ⏱ 大约 12 分钟

## 这位选手什么脾气

OpenMediaVault（简称 OMV）是"极简实干家"——它基于 Debian Linux，只做 NAS 该做的事：文件共享、磁盘管理、用户权限、远程访问。界面不华丽，但该有的功能一样不少。

它常被形容成"毛坯房"：系统给你打好地基，想住得舒服还得自己装修（装插件、配 Docker）。愿意动手的人，能把它调教成非常趁手的家庭服务器。

| 项目 | 说明 |
| --- | --- |
| 类型 | 开源免费 |
| 基础 | Debian Linux（OMV 7 基于 Debian 12 Bookworm） |
| 架构 | x86-64（也支持 ARM 部分平台） |
| 文件系统 | ext4 / Btrfs（新版支持） |
| Docker | 通过 omv-extras 插件 + Docker 管理器 |
| 面向 | 家庭与小型办公室（SOHO） |

## 基本信息

按官网说法，OMV 是一个基于 Debian 的开源 NAS 解决方案，通过模块化框架提供 SSH、(S)FTP、SMB/CIFS、RSync 等服务，还能通过插件扩展。[官方网站](https://www.openmediavault.org/) 明确说它"主要面向家庭和小型办公室，但不限于此"。

## 它的长处

1. **轻量、门槛低**：安装镜像几百 MB，老电脑（比如 H61 主板的机器）就能跑，功耗很低
2. **Debian 底盘稳**：底层是 Debian，稳定性和软件生态有保障
3. **模块化扩展**：通过 omv-extras 插件可以装 Docker CE、Portainer，进而跑 Jellyfin、Nextcloud、qBittorrent 等
4. **零成本**：开源免费，自己找硬件装
5. **OMV 7 界面升级**：基于 Angular 16 重构，比老版本现代不少，还优化了移动端布局

## 它的短板

- **"毛坯房"属性**：高级功能要自己折腾，新手得有心理准备
- **中文体验一般**：界面和文档以英文为主，中文社区比飞牛/群晖小
- **数据保护要自己补**：完整的 RAID/快照方案不如 TrueNAS 开箱即用

## 适合这样的人

- 想零成本把旧电脑变 NAS
- 喜欢 Debian 的稳定与自由
- 愿意动手装插件、配 Docker
- 低功耗、小型家庭服务器场景

## 这些人再想想

- 完全零基础、想要开箱即用（那更适合群晖/飞牛）
- 追求开箱即用的完善数据保护（那更适合 TrueNAS）

## 写在最后

OMV 是"Debian 底盘 + NAS 界面 + 插件扩展"的组合。轻量、稳定、自由，适合愿意动手的人。想要开箱即用就选群晖/飞牛，想要极致数据保护就选 TrueNAS。
