# 3.3 威联通 QTS / QuTS hero

> 定位：功能全面、弹性与性价比兼顾

## 本章目标

- 了解 QTS 与 QuTS hero 的区别
- 知道威联通适合哪些人

## 概览

威联通（QNAP）提供两套系统：

| 系统 | 文件系统 | 特点 |
| --- | --- | --- |
| QTS | ext4（可选 ZFS 部分机型） | 传统、生态成熟、兼容性好 |
| QuTS hero | ZFS | 数据完整性更强，吃内存 |

> 💡 选型关键：想要 ZFS 的数据保护能力，选 QuTS hero；更看重兼容与轻量，选 QTS。详见 [5.1 文件系统](../05-存储与数据保护/5.1-文件系统.md)。

## 优势

1. **硬件规格激进**：同价位 CPU/内存常高于群晖，带核显机型适合影音转码。
2. **功能全面**：虚拟机、容器、影音、监控、办公套件一应俱全。
3. **弹性**：支持 PCIe 扩展（网卡、显卡、HBA）。
4. **价格相对合理**：性价比优于群晖。

## 局限

- **界面相对复杂**：功能多导致新手上手门槛高于群晖。
- **中文体验略逊**：本土化程度不如飞牛/群晖。
- **安全历史**：曾因公网暴露导致勒索软件事件，务必重视 [6.5 安全加固](../06-网络与远程访问/6.5-安全加固.md)。
- **风扇噪音**：部分机型噪音偏大。

## 适合谁

- 想要群晖的体验但预算有限
- 需要虚拟机、Docker、PCIe 扩展
- 影音转码需求（选带核显机型）

## 不适合谁

- 追求极简界面的纯新手
- 对噪音极度敏感

## 小结

威联通是"功能与性价比的平衡点"。愿意花点时间学习的人，能获得很高回报。
