# B 常见问题 FAQ

## 选型类

**Q：群晖和威联通选哪个？**
A：群晖更易用、生态成熟；威联通性价比和硬件规格更好。重视省心选群晖，重视配置与扩展选威联通。详见 [3.1](../03-平台横评与选型/3.1-六大平台横向对比.md)。

**Q：旧电脑能做 NAS 吗？**
A：可以。CasaOS、飞牛 fnOS 都适合旧机改造。注意功耗、电源稳定性和硬盘架。详见 [3.5](../03-平台横评与选型/3.5-CasaOS.md)、[2.4](../02-硬件选型/2.4-整机方案与预算.md)。

**Q：必须用 ECC 内存吗？**
A：家用不必强求，但 ZFS 场景推荐。预算有限时，优先把钱花在硬盘和备份上。

## 存储类

**Q：RAID 到底是什么？能替代备份吗？**
A：RAID 用多块盘换取冗余或性能，防的是单盘物理故障。它**不能**防误删、勒索、火灾、失窃。详见 [2.3](../02-硬件选型/2.3-容量规划与RAID基础.md)、[5.4](../05-存储与数据保护/5.4-备份3-2-1原则.md)。

**Q：快照算备份吗？**
A：不算。快照和原数据在同一台设备上。详见 [5.3](../05-存储与数据保护/5.3-快照与版本管理.md)。

**Q：硬盘多久该换？**
A：没有固定年限，看 SMART 趋势和健康状况。出现异常指标先备份再处理。详见 [5.5](../05-存储与数据保护/5.5-硬盘健康监控.md)。

**Q：SMR 盘能不能用？**
A：不推荐用于 RAID（重建风险高）。购买前确认是 CMR。详见 [2.2](../02-硬件选型/2.2-硬盘选型.md)。

## 网络类

**Q：没有公网 IP 怎么外网访问？**
A：用 Tailscale / WireGuard 组网 VPN，或 Cloudflared 等内网穿透。详见 [6.2](../06-网络与远程访问/6.2-远程访问方案对比.md)。

**Q：内网速度慢怎么办？**
A：检查网口协商速率、网线类别、交换机端口，以及硬盘是否是瓶颈。详见 [6.1](../06-网络与远程访问/6.1-局域网基础.md)。

**Q：可以直接把 NAS 端口映射到公网吗？**
A：强烈不建议。至少要做到强密码 + HTTPS + 限制访问 + 及时更新。优先用 VPN。详见 [6.5](../06-网络与远程访问/6.5-安全加固.md)。

## 应用类

**Q：Docker 容器删了，数据还在吗？**
A：只要数据目录映射到了 NAS 存储就在。没映射的数据会随容器一起消失。详见 [7.1](../07-应用服务/7.1-Docker基础.md)。

**Q：4K 视频卡顿怎么办？**
A：优先让客户端直播原片；需要转码时开启硬件转码（核显），或降低码率。详见 [7.2](../07-应用服务/7.2-影音中心.md)。

**Q：NAS 能跑 DeepSeek 吗？**
A：可以跑蒸馏小模型（如 7B），需要足够内存（16GB+）。详见 [7.5](../07-应用服务/7.5-自托管AI.md)。

## 综合类

**Q：我该从哪里开始？**
A：见 [0.2 如何使用本指南](../00-前言/如何使用本指南.md) 的三条阅读路径。

**Q：这台机器可以做 All in One 吗？**
A：技术上可以（PVE + NAS + 其他服务），但复杂度高、故障影响面大。家庭用户建议量力而行。详见 [8.1](../08-进阶主题/8.1-虚拟机与容器.md)。
