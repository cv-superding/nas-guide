# 常见问题：卡住了先来这儿看看

这一页按"你正在纠结什么"来组织。遇到问题时回来翻，说不定答案就在这儿。

## 还在纠结要不要买

**Q：群晖和威联通选哪个？**

A：简单说，群晖更省心、生态成熟；威联通配置和性价比更好。重视"别让我折腾"选群晖，重视"同样的钱买到更多"选威联通。详细对比在 [3.1](../../docs/03-平台横评与选型/3.1-六大平台横向对比.md)。

**Q：旧电脑能做 NAS 吗？**

A：能，而且是不错的入门方式。飞牛 fnOS、CasaOS 都对老机器很友好。注意功耗、电源稳定性和硬盘架就行。见 [3.5](../../docs/03-平台横评与选型/3.5-CasaOS.md)、[3.6](../../docs/03-平台横评与选型/3.6-飞牛fnOS.md)。

**Q：必须用 ECC 内存吗？**

A：家用不必强求。预算有限的话，把钱花在可靠的硬盘和真正的备份上，回报更大。

**Q：我现在到底需不需要 NAS？**

A：先做 [1.3 的自测](../../docs/01-认识NAS/1.3-谁需要NAS.md)，再走一遍 [一周上手计划](../../docs/00-前言/一周上手计划.md) 的第一天。答案往往自己就出来了。

## 数据安全那些事

**Q：RAID 到底算不算备份？**

A：**不算。** RAID 防的是单块盘物理损坏，防不了误删、勒索、火灾、失窃。这句话我们在 [2.3](../../docs/02-硬件选型/2.3-容量规划与RAID基础.md) 和 [5.4](../../docs/05-存储与数据保护/5.4-备份3-2-1原则.md) 反复讲，因为它太重要了。

**Q：快照算备份吗？**

A：不算。快照和原数据在同一台机器上，机器没了它也没了。见 [5.3](../../docs/05-存储与数据保护/5.3-快照与版本管理.md)。

**Q：硬盘多久该换一次？**

A：没有固定年限，看 S.M.A.R.T. 的趋势和健康状况。指标持续恶化就先备份再处理。见 [5.5](../../docs/05-存储与数据保护/5.5-硬盘健康监控.md)。

**Q：SMR 盘到底能不能用？**

A：做 RAID 不推荐——重建慢且风险高。买盘前确认是 CMR。见 [2.2](../../docs/02-硬件选型/2.2-硬盘选型.md)。

**Q：备份怎么才算"真的"？**

A：过一遍 3-2-1：3 份数据、2 种介质、1 份异地。而且**没验证过恢复的备份等于没有备份**。见 [5.4](../../docs/05-存储与数据保护/5.4-备份3-2-1原则.md)。

## 网络连不上、速度慢

**Q：没有公网 IP，怎么从外面访问？**

A：用 Tailscale / WireGuard 这类组网 VPN，或 Cloudflared 内网穿透。不用公网 IP，安全性还好。见 [6.2](../../docs/06-网络与远程访问/6.2-远程访问方案对比.md)。

**Q：内网传文件好慢，怎么办？**

A：逐环检查——网口协商速率、网线类别、交换机端口、客户端硬盘。任何一环是百兆，整体就被卡住。见 [6.1](../../docs/06-网络与远程访问/6.1-局域网基础.md)。

**Q：能把 NAS 端口直接映射到公网吗？**

A：**强烈不建议。** 非要这么做，至少要做到强密码 + HTTPS + 限制来源 IP + 及时更新。优先用 VPN。见 [6.5](../../docs/06-网络与远程访问/6.5-安全加固.md)。

**Q：外网访问就是慢，是我的问题吗？**

A：多半不是配置问题。家庭宽带上传带宽通常很小（30～50Mbps），传大文件就是慢。这是物理限制。

## Docker 和应用的坑

**Q：容器删了，数据还在吗？**

A：只要数据目录用 `volumes` 映射到了 NAS 存储，就在。没映射的数据会随容器一起消失。这是新手最常踩的坑，见 [7.1](../../docs/07-应用服务/7.1-Docker基础.md)。

**Q：4K 视频卡顿怎么办？**

A：优先让客户端直播原片；需要转码时开硬件转码（核显），或降低码率。见 [7.2](../../docs/07-应用服务/7.2-影音中心.md)。

**Q：NAS 能跑 DeepSeek 吗？**

A：能跑蒸馏小模型（如 7B），需要 16GB 以上内存。从 `deepseek-r1:7b` 起步。见 [7.5](../../docs/07-应用服务/7.5-自托管AI.md)。

**Q：我装了好多服务，机器越来越卡？**

A：检查资源占用，限制容器内存/CPU，关掉不用的服务。[8.3 性能调优](../../docs/08-进阶主题/8.3-性能调优.md) 和 [8.5 监控告警](../../docs/08-进阶主题/8.5-监控与告警.md) 能帮你定位。

## 综合

**Q：我该从哪里开始读？**

A：[0.2 如何使用本指南](../../docs/00-前言/如何使用本指南.md) 的三条阅读路径，或者直接按 [一周上手计划](../../docs/00-前言/一周上手计划.md) 走。

**Q：能不能做 All in One（一台机器跑所有）？**

A：技术上能，但复杂度和故障影响面都大。家庭用户量力而行。见 [8.1](../../docs/08-进阶主题/8.1-虚拟机与容器.md) 和第 [11 章](../../docs/11-PVE底层方案/README.md) 的详细利弊分析。

**Q：我想再装点应用，不知道装什么？**

A：逛逛第 [10 章自托管应用图谱](../../docs/10-自托管应用图谱/README.md)，按场景列了文件、影音、效率、网络各类应用。记住它是地图不是购物清单，只装你真会用的。

**Q：什么是"直通"，为什么装 NAS 虚拟机时要搞？**

A：直通是把物理硬件（硬盘控制器、显卡）直接交给虚拟机独占。NAS 系统需要直接看到物理硬盘才能做 SMART 监控和电源管理，所以这步很关键。见 [11.2](../../docs/11-PVE底层方案/11.2-在PVE上装NAS.md)。

**Q：怎么学别人那套 homelab 配置？**

A：第 [12 章](../../docs/12-Homelab实战样板/README.md) 拆解了多个真实开源项目——看它们的仓库结构、Docker Compose 组织和备份策略，学思路而不是照抄配置。

**Q：合上笔记本盖子 NAS 就失联了？**

A：这是拿笔记本当 NAS 的经典坑——默认合盖休眠。去电源设置里关掉"合盖休眠"。见 [3.7](../../docs/03-平台横评与选型/3.7-树莓派与软路由.md)。
