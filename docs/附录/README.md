## 一句老实话

> ⚠️ 命令这东西，**看不懂就别复制粘贴**。尤其是带 `rm`、`dd`、`zfs destroy` 这些词的。执行前花十秒想想它在干什么，能省掉十小时的恢复数据时间。

## 一个小提醒

附录里的链接和命令会随着系统版本变化。如果发现某个命令在新版本不管用了，欢迎提 Issue 告诉我们，我们及时更新——这份文档想一直有用，就得靠大家一起维护。
