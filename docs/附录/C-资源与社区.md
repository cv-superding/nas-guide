## 如何提问

在社区求助时，附上以下信息能更快得到帮助：

1. 硬件配置（CPU、内存、硬盘型号与数量）
2. 系统及版本
3. 你想做什么、实际发生了什么
4. 完整错误提示（截图打码个人信息）
5. 你已经尝试过什么

## 小结

官方文档优先、社区补充。提问时信息越具体，越容易得到有用的回答。

## 小结

善用资源，但记得：任何来源的建议，都要理解后再应用到自己的机器上。
