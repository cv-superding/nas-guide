# 14.1 Portainer：用界面管容器

## 它解决什么问题

第 7 章我们一直用命令行 `docker compose` 管理容器。好用是好用，但每次都要 SSH 登录、记命令。

Portainer 给 Docker 套了个**图形界面**：在浏览器里就能查看容器、看日志、重启、更新镜像、甚至直接编辑 Compose。不想敲命令的人，这会舒服很多。

> 💡 多个 homelab 项目都用 Portainer 管理容器（见 [12.2](12.2-值得借鉴的实践.md) 与 [致谢](../../CREDITS.md)）。

## 部署

示例在 [`examples/docker-compose/portainer/docker-compose.yml`](../../examples/docker-compose/portainer/docker-compose.yml)：

```yaml
version: "3.8"
services:
  portainer:
    image: portainer/portainer-ce:latest
    container_name: portainer
    restart: unless-stopped
    security_opt:
      - no-new-privileges:true
    volumes:
      - /var/run/docker.sock:/var/run/docker.sock
      - /volume1/docker/portainer:/data
    ports:
      - "9000:9000"
      - "8000:8000"
```

几点说明：

- `docker.sock` 映射让 Portainer 能管理宿主机的 Docker——**这等于给它最高权限**，所以只在你信任的环境里用
- `/data` 持久化 Portainer 自己的配置
- 9000 是 HTTPS 界面，8000 是 HTTP（首次设置用）

## 首次配置

1. 浏览器访问 `https://<NAS的IP>:9000`（首次可能走 8000）
2. 设置管理员密码
3. 选择管理本地 Docker 环境（Local）
4. 进入后就能看到容器、镜像、网络、卷的管理界面

> ⚠️ 首次设置完，建议关掉 8000 端口映射，只保留 9000，并配上认证。公网访问务必加 VPN 或反代 + HTTPS，见 [第 6 章](../06-网络与远程访问/README.md)。

## 能干什么

- 容器的启动/停止/删除/重启
- 实时查看日志
- 用 Web 编辑器创建 Stack（等价于 docker-compose）
- 镜像更新、清理
- 模板一键部署常用应用

> 💡 对新手来说，最实用的是"看日志"和"重启容器"——排障时不用记 `docker logs -f` 了。

## 实测验证

1. 部署后访问界面，能看到已有的容器列表
2. 通过界面启动/停止一个测试容器
3. 确认 `/data` 目录有数据写入（重启 Portainer 配置不丢）

## 和原生 Docker 命令怎么选

| 场景 | 建议 |
| --- | --- |
| 喜欢命令行、做自动化 | 继续用 `docker compose`（[7.1](../07-应用服务/7.1-Docker基础.md)） |
| 偶尔管一下、想要直观 | Portainer |
| 家里人也要用 | Portainer（界面友好） |

两者不冲突——Portainer 管理的容器，命令行照样能操作。

## 写在最后

Portainer 是"给 Docker 装了个界面"。省心，但要意识到 `docker.sock` 的权限风险，别暴露公网。

## 动手试试

1. 部署 Portainer，用界面查看你现有的容器。
2. 通过界面创建一个简单的 Stack（比如一个 nginx）。
