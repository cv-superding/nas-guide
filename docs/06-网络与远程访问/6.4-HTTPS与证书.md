## 这一节能帮你

- 理解 HTTPS 与证书的作用

## 为什么需要 HTTPS

- **加密**：防止传输内容被窃听（尤其在公网）
- **完整性**：防止内容被篡改
- **可信**：浏览器验证网站身份

NAS 管理界面和自托管服务若走明文 HTTP，密码和数据可能被中间人窃取。

## 证书类型

| 类型 | 说明 | 适合 |
| --- | --- | --- |
| Let's Encrypt | 免费、自动续期、受信任 | 有域名的公开服务 ✅ |
| 自签名证书 | 免费、自己签发 | 纯内网使用 |
| 商业证书 | 付费、功能丰富 | 企业场景 |

## 方案一：Let's Encrypt（推荐）

通过反向代理（如 Nginx Proxy Manager / Caddy / Traefik）自动申请和续期：

- NPM：在代理主机设置中一键申请 Let's Encrypt 证书
- Caddy：配置域名后自动申请，几乎零配置
- 需要域名解析到你的服务器，并能通过 HTTP-01 或 DNS-01 验证

> 💡 DNS-01 验证适合无公网 IP 的场景（通过 API 自动添加 DNS 记录），配合 Cloudflared 等很流行。

## 方案二：自签名证书（纯内网）

仅在内网访问时可用，但浏览器会提示"不安全"，需手动信任证书。适合不想买域名、只在家里用的场景。

```bash
# 生成自签名证书示例
openssl req -x509 -nodes -days 365 -newkey rsa:2048 \
  -keyout nas.key -out nas.crt \
  -subj "/CN=nas.local"
```

> ⚠️ 自签名证书无法验证身份，仅在可信内网使用。公网服务请务必用受信任的证书。

## 强制 HTTPS

启用 HTTPS 后：

1. 设置 HTTP 自动跳转到 HTTPS
2. 开启 HSTS（谨慎：设置后浏览器会强制 HTTPS，配置错误会导致无法访问）
3. 更新所有访问链接为 `https://`

## 证书维护

- Let's Encrypt 证书 90 天有效期，务必配置**自动续期**
- 监控证书到期时间，见 [8.5 监控与告警](../08-进阶主题/8.5-监控与告警.md)
- 私钥妥善保管，不要提交到仓库（见 `.gitignore`）

## 写在最后

有域名就用 Let's Encrypt + 自动续期；纯内网可用自签名证书。启用 HTTPS 后记得强制跳转并监控证书有效期。

## 动手试试

1. 为你的一个服务启用 HTTPS，用浏览器确认地址栏出现锁形图标。
2. 检查证书自动续期是否已配置。
