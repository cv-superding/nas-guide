## 本章目标

- 用一份清单确认搭建成功
- 知道哪些问题需要在进入下一章前解决

## 基础验收

- [ ] NAS 能正常开机、Web 界面可访问
- [ ] 固定 IP / 主机名设置生效，重启后仍可访问
- [ ] 系统已更新到最新稳定版本
- [ ] 存储池/卷状态正常，容量符合预期
- [ ] 管理员密码已修改为强密码，另建了日常用户
- [ ] 共享文件夹可正常读写（电脑与手机各测一次）
- [ ] 数据迁移完成且校验通过
- [ ] 时区正确、NTP 时间同步开启

## 数据安全验收

- [ ] RAID/存储池状态正常（无降级、无告警）
- [ ] 已建立至少一个初始快照
- [ ] 已配置至少一份**真正的备份**（不是只在 NAS 内复制），见 [5.4](../05-存储与数据保护/5.4-备份3-2-1原则.md)
- [ ] 已开启硬盘健康监控与告警，见 [5.5](../05-存储与数据保护/5.5-硬盘健康监控.md)
- [ ] 已确认通知渠道（邮件/App）可以收到测试消息

## 网络验收

- [ ] 内网访问速度达到预期（千兆约 100MB/s 量级）
- [ ] 已规划远程访问方式（先配置 VPN，别急着端口转发），见 [6.2](../06-网络与远程访问/6.2-远程访问方案对比.md)
- [ ] 默认密码、UPnP、不必要的端口已关闭，见 [6.5](../06-网络与远程访问/6.5-安全加固.md)

## 速测命令

```bash
# 查看磁盘与挂载
df -h
lsblk

# 简单写入速度测试（1GB）
dd if=/dev/zero of=/mnt/nas/testfile bs=1M count=1024 conv=fdatasync
rm /mnt/nas/testfile

# 查看硬盘健康（需安装 smartmontools）
sudo smartctl -a /dev/sda
```

## 如果某项不通过

| 问题 | 建议 |
| --- | --- |
| 速度远低于预期 | 检查网线/网口协商速率、硬盘是否 SMR、是否跨网段 |
| 存储池降级 | 检查哪块盘掉线，尽快处理，见 [5.2](../05-存储与数据保护/5.2-RAID与存储池实战.md) |
| 收不到通知 | 检查 SMTP 设置、垃圾邮件箱、网络连通性 |
| 外网访问不通 | 先确认内网正常，再排查 DDNS/端口/VPN，见第 6 章 |

## 小结

全部勾选后，你已经有了一台"可用且安全"的 NAS。接下来可以进入 [第 5 章](../05-存储与数据保护/README.md) 深化数据保护，或按兴趣跳到第 6、7 章。
