# 4.5 验收：逐项打勾，确认真的搞定了

> 📌 先读：[4.4 首次数据迁移](4.4-首次数据迁移.md) · ⏱ 大约 10 分钟

## 基础项

- [ ] NAS 能开机，Web 界面能访问
- [ ] 固定 IP / 主机名生效，重启后还能访问
- [ ] 系统更新到最新稳定版
- [ ] 存储池/卷状态正常，容量符合预期
- [ ] 管理员密码改成强密码，另建了日常用户
- [ ] 共享文件夹能读写（电脑、手机各测一次）
- [ ] 数据迁移完成且校验通过
- [ ] 时区正确、NTP 对时开启

## 数据安全项

- [ ] RAID / 存储池状态正常（没降级、没告警）
- [ ] 建了至少一个初始快照
- [ ] 配了至少一份**真正的备份**（不是只在 NAS 内复制），见 [5.4](../05-存储与数据保护/5.4-备份3-2-1原则.md)
- [ ] 开了硬盘健康监控与告警，见 [5.5](../05-存储与数据保护/5.5-硬盘健康监控.md)
- [ ] 通知渠道测过，能收到消息

## 网络项

- [ ] 内网访问速度达标（千兆约 100MB/s 量级）
- [ ] 规划好了远程访问方式（先 VPN，别急着端口转发），见 [6.2](../06-网络与远程访问/6.2-远程访问方案对比.md)
- [ ] 默认密码、UPnP、不必要的端口都关了，见 [6.5](../06-网络与远程访问/6.5-安全加固.md)

## 速测命令

```bash
df -h                    # 看磁盘占用
lsblk                    # 看块设备

# 写 1GB 测速
dd if=/dev/zero of=/mnt/nas/testfile bs=1M count=1024 conv=fdatasync
rm /mnt/nas/testfile

sudo smartctl -a /dev/sda   # 硬盘健康（需装 smartmontools）
```

## 哪项没通过

| 问题 | 建议 |
| --- | --- |
| 速度远低于预期 | 查网线/网口协商速率、硬盘是不是 SMR、有没有跨网段 |
| 存储池降级 | 查哪块盘掉线，尽快处理，见 [5.2](../05-存储与数据保护/5.2-RAID与存储池实战.md) |
| 收不到通知 | 查 SMTP 设置、垃圾邮件箱、网络连通性 |
| 外网访问不通 | 先确认内网正常，再排查 DDNS/端口/VPN，见第 6 章 |

## 写在最后

全部打勾，你就有一台"可用且安全"的 NAS 了。接下来可以去 [第 5 章](../05-存储与数据保护/README.md) 深化数据保护，或按兴趣跳到第 6、7 章。
