# 4.1 动手之前，先做这几件事

> 📌 先读：[第 2 章](../02-硬件选型/README.md)、[第 3 章](../03-平台横评与选型/README.md) · ⏱ 大约 10 分钟

## 最重要的一件事：备份

这句话值得单独占一段：

> ⚠️ **安装系统会清空目标磁盘，且不可恢复。**

所以动手前请确认：

- [ ] 目标盘上的原有数据已备份到别处（另一块硬盘、云盘都行）
- [ ] 备份**验证过能读出来**（不是复制完就完事）
- [ ] 你分得清系统盘和数据盘，不会手滑选错

这不是吓唬人。论坛里"装系统把照片盘格了"的帖子，隔三差五就有人发。

## 硬件检查

- [ ] 硬盘数量、容量跟计划一致
- [ ] SATA 线、电源线插牢
- [ ] 内存插好、能识别
- [ ] 电源功率够多块盘同时启动
- [ ] 机箱风道通畅
- [ ] 网卡连得上

## 工具准备

| 要准备什么 | 说明 |
| --- | --- |
| U 盘（≥8GB） | 做系统启动盘 |
| 另一台电脑 | 做启动盘、访问管理界面 |
| 一根网线 | 初次配置建议有线，稳 |
| 路由器管理权限 | 查 NAS 的 IP、必要时做端口映射 |
| 系统镜像 | 从官方渠道下载，校验 SHA256 |

> 💡 下载镜像后校验一下 SHA256，确保文件没被篡改。命令见 [附录 A](../附录/A-命令速查.md)。

## 网络先想好

1. **IP**：建议给 NAS 分配固定 IP 或在路由器做绑定，不然重启后找不到它
2. **网段**：记下你家的网段（比如 192.168.1.x）
3. **主机名**：起个好记的名字，比如 `nas-home`

详见 [6.1 局域网基础](../06-网络与远程访问/6.1-局域网基础.md)。

## 存储布局也要先定

- 系统装在哪？（小容量 SSD / U 盘 / 单独一块盘）
- 数据盘有哪几块？做什么 RAID？
- 要不要留一块热备盘？

参考 [2.3 容量与 RAID](../02-硬件选型/2.3-容量规划与RAID基础.md) 和 [5.2 存储池实战](../05-存储与数据保护/5.2-RAID与存储池实战.md)。

## 写在最后

准备阶段的核心就八个字：**备份 + 规划**。表填完、清单勾完，再往下走。
