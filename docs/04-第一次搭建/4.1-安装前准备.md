## 本章目标

- 完成安装前的硬件、数据、网络准备
- 避免"装到一半才发现缺东西"

## 数据备份（最重要）

> ⚠️ 安装系统会格式化目标磁盘，**不可恢复**。开始之前，请确认：
>
> - [ ] 目标盘上原有数据已备份到别处（另一块硬盘、云盘均可）
> - [ ] 备份已验证可读（不是"复制完就完事"）
> - [ ] 系统盘与数据盘已分清，不会误操作

## 硬件检查清单

- [ ] 硬盘数量、容量与计划一致
- [ ] SATA 线、电源线连接牢固
- [ ] 内存已插好、识别正常
- [ ] 电源功率足够多盘启动
- [ ] 机箱风道通畅
- [ ] 网卡连接正常

## 工具准备

| 项目 | 说明 |
| --- | --- |
| U 盘（≥8GB） | 制作系统启动盘 |
| 另一台电脑 | 用于制作启动盘、访问管理界面 |
| 网线 | 初次配置建议有线连接 |
| 路由器管理权限 | 用于查看 NAS 的 IP、必要时做端口映射 |
| 系统镜像 | 从官方渠道下载，校验完整性 |

> 💡 下载系统镜像后建议校验 SHA256，确保文件未被篡改。命令示例见 [附录 A 命令速查](../附录/A-命令速查.md)。

## 网络规划

提前想好：

1. **IP 分配**：建议给 NAS 分配固定/保留 IP，便于长期访问。
2. **网段**：记下你的局域网网段（如 192.168.1.x）。
3. **主机名**：起一个易记的名字，如 `nas-home`。

详见 [6.1 局域网基础](../06-网络与远程访问/6.1-局域网基础.md)。

## 规划存储布局

安装前先决定：

- 系统装在哪？（小容量 SSD / U 盘 / 单独盘）
- 数据盘有哪几块？做什么 RAID？
- 是否预留热备盘？

参考 [2.3 容量规划与 RAID 基础](../02-硬件选型/2.3-容量规划与RAID基础.md) 和 [5.2 RAID 与存储池实战](../05-存储与数据保护/5.2-RAID与存储池实战.md)。

## 小结

准备阶段的核心是"备份 + 规划"。把上面的表填满，安装时就不会手忙脚乱。
