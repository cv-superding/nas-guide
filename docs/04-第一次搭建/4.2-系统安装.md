## 这一节能帮你

- 掌握"制作启动盘 → 安装系统 → 首次登录"的通用流程
- 了解各平台的安装差异

> ⚠️ 安装会清空目标盘数据！再次确认已备份、已选对磁盘。

## 通用流程

```mermaid
flowchart LR
    A[下载官方镜像] --> B[制作启动盘]
    B --> C[从 U 盘启动]
    C --> D[按向导安装]
    D --> E[重启并登录 Web 界面]
```

## 步骤 1：下载镜像

- 从各系统**官方网站**下载 ISO/IMG 镜像。
- 校验 SHA256（见附录 A）。
- ⚠️ 不要从第三方网盘下载"修改版"镜像，安全风险极高。

## 步骤 2：制作启动盘

常用工具：Rufus（Windows）、Etcher（跨平台）、`dd` 命令（Linux/macOS）。

```bash
# Linux 示例：将镜像写入 U 盘（/dev/sdX 请替换为实际设备！）
sudo dd if=system.img of=/dev/sdX bs=4M status=progress conv=fsync
```

> ⚠️ `dd` 命令写错设备会毁掉整块盘。执行前用 `lsblk` 确认设备名。

## 步骤 3：从 U 盘启动

1. 将 U 盘插入 NAS 主机，开机按 F12/Del 等键进入启动菜单。
2. 选择从 U 盘启动。
3. 进入安装向导。

## 步骤 4：按向导安装

不同系统界面不同，但核心决策一致：

- **选择安装目标盘**：⚠️ 再次确认不是数据盘
- **设置管理员账号与密码**：使用强密码
- **网络配置**：建议有线 + DHCP，装完再改固定 IP
- **存储配置**：可先跳过复杂 RAID，装完在 Web 界面配置（新手更稳妥）

### 平台要点对照

| 平台 | 安装特点 |
| --- | --- |
| 飞牛 fnOS | 图形化向导，支持自装 x86，全程中文，较友好 |
| CasaOS | 通常先装 Debian/Ubuntu，再一条命令安装 CasaOS |
| 群晖/威联通 | 整机自带系统，首次开机用向导初始化，无需装系统 |
| TrueNAS | 从 U 盘安装到目标盘，安装后从 Web 管理 |
| 树莓派 | 用官方工具烧录系统卡，启动后配置 |

## 步骤 5：首次登录

1. 在路由器管理页找到 NAS 的 IP；或用系统提供的发现工具。
2. 浏览器访问 `https://<NAS的IP>`（部分系统用 http）。
3. 用安装时设置的账号登录。

> 💡 首次登录若提示证书不受信任，属正常现象（自签名证书），确认后继续。HTTPS 配置详见 [6.4 HTTPS 与证书](../06-网络与远程访问/6.4-HTTPS与证书.md)。

## 常见问题

- **找不到 IP**：检查网线、用手机 App 扫描、或登录路由器看已连接设备。
- **无法启动**：检查启动盘是否正确、BIOS 是否允许 U 盘启动。
- **装完没界面**：等待首次初始化完成（可能几分钟），确认访问端口正确。

## 写在最后

安装本质是"启动盘 → 向导 → 登录"。慢一点，每一步都确认目标磁盘正确。

## 动手试试

1. 记录你的 NAS 首次登录 IP 与管理员账号（密码不要明文写进文档）。
2. 如果安装失败，写下错误提示，便于在社区求助。
