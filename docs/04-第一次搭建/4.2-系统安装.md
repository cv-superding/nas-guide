# 4.2 装系统：其实就四步

> 📌 先读：[4.1 安装前准备](4.1-安装前准备.md) · ⏱ 大约 20 分钟

> ⚠️ 安装会清空目标盘数据！再确认一次：备份好了吗？选对盘了吗？

## 大致流程

```mermaid
flowchart LR
    A[下载官方镜像] --> B[做启动盘] --> C[U盘启动] --> D[跟着向导装] --> E[重启登录]
```

## 第一步：下载镜像

- 从**官方网站**下 ISO/IMG 镜像
- 校验 SHA256（见 [附录 A](../附录/A-命令速查.md)）
- ⚠️ 别从第三方网盘下"修改版"，安全风险极高

## 第二步：做启动盘

常用工具：Rufus（Windows）、Etcher（跨平台）、`dd`（Linux/macOS）。

```bash
# Linux 示例：把镜像写进 U 盘（/dev/sdX 一定换成你自己的设备！）
sudo dd if=system.img of=/dev/sdX bs=4M status=progress conv=fsync
```

> ⚠️ `dd` 命令写错设备会毁掉整块盘。执行前用 `lsblk` 确认设备名，盯准了再回车。

## 第三步：从 U 盘启动

1. 插好 U 盘，开机按 F12/Del 之类的键进启动菜单
2. 选从 U 盘启动
3. 进入安装向导

有位数巢笔记的作者拿 ThinkPad 装飞牛，把这一步写得挺实在：开机按 F1 进 BIOS（不同牌子试 F2/F10/Del），把启动模式改成 UEFI、**关掉安全启动（Secure Boot）**，然后 U 盘设第一启动项。原文见 [这里](https://www.shunot.com/nas/1000.html)。

## 第四步：跟着向导装

不同系统界面不一样，但要决定的事差不多：

- **选安装目标盘**：⚠️ 再次确认不是数据盘
- **设管理员账号密码**：用强密码
- **网络**：建议有线 + DHCP，装完再改固定 IP
- **存储**：新手可以先跳过复杂 RAID，装完在 Web 界面慢慢配

### 各平台要点

| 平台 | 安装特点 |
| --- | --- |
| 飞牛 fnOS | 图形化向导，全程中文，较友好；官方步骤见 [飞牛帮助中心](https://help.fnnas.com/articles/v1/start/install-os) |
| CasaOS | 一般先装 Debian/Ubuntu，再一条命令装 CasaOS |
| 群晖/威联通 | 整机自带系统，首次开机用向导初始化，不用装系统 |
| TrueNAS | 从 U 盘装到目标盘，之后从 Web 管理 |
| 树莓派 | 用官方工具烧录系统卡，启动后配置 |

飞牛安装的完整过程，飞牛论坛有篇用旧 ThinkPad X201s 做示范的教程写得很细，从关 Secure Boot 到图形界面一路下一步，十分钟装完，见 [这里](https://club.fnnas.com/forum.php?mod=viewthread&tid=50006)。

## 重启，登录

1. 在路由器管理页找到 NAS 的 IP，或用系统的查找工具
2. 浏览器访问 `https://<NAS的IP>`（有的系统用 http）
3. 用装系统时设的账号登录

> 💡 首次登录提示证书不受信任很正常（自签名证书），确认继续即可。HTTPS 配置见 [6.4](../06-网络与远程访问/6.4-HTTPS与证书.md)。

## 卡住了怎么办

- **找不到 IP**：检查网线、用手机 App 扫、或登录路由器看已连接设备
- **无法启动**：检查启动盘对不对、BIOS 允不允许 U 盘启动
- **装完没界面**：等首次初始化完成（可能几分钟），确认访问端口

## 写在最后

安装本质就是"启动盘 → 向导 → 登录"。慢一点，每一步都确认目标磁盘对不对。

## 动手试试

1. 记下你的 NAS 首次登录 IP 和管理员账号（密码别明文写进文档）。
2. 如果装失败了，把错误提示记下来，方便在社区求助。
