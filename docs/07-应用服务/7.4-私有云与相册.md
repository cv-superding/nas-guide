# 7.4 私有云与相册：把网盘搬回家

> 📌 先读：[7.1 Docker 基础](7.1-Docker基础.md)、[6.4 HTTPS](../../docs/06-网络与远程访问/6.4-HTTPS与证书.md) · ⏱ 大约 15 分钟

## 先选对工具

| 需求 | 方案 | 特点 |
| --- | --- | --- |
| 文件 + 协作 + 日历 | Nextcloud | 功能全面，像自建网盘 |
| AI 相册（人脸、聚类） | Immich | 现代、体验接近大厂相册 ✅ |
| 轻量同步 | Syncthing | 去中心化，见 [7.3](7.3-下载与同步.md) |
| 厂商相册 | 群晖 Photos / 飞牛相册 | 简单，跟系统整合 |

## Nextcloud

功能：文件存储、在线文档、日历、联系人、分享链接等。

部署示例在 [`examples/docker-compose/nextcloud/`](../../examples/docker-compose/nextcloud/docker-compose.yml)。

要点：数据库和 data 目录都要持久化；公网访问必须配 HTTPS；它对硬盘随机 IO 敏感， SSD 或缓存加速会更顺。

> ⚠️ Nextcloud 比较重，低配机器会吃力。只想备份照片的话，Immich 或厂商 App 更合适。

## Immich（AI 相册）

功能：照片/视频备份、人脸聚类、时间线、地图、共享相册，手机 App 能自动备份。

配置示例在 [`examples/docker-compose/immich/`](../../examples/docker-compose/immich/docker-compose.yml)（简化版，生产用请补全 Redis 等服务）。它需要 PostgreSQL，人脸聚类这类智能功能比较吃内存——资源紧张的话可以关掉 AI 功能。

## 顺带说说密码管理

很多人也在 NAS 上自托管密码管理器（比如 Vaultwarden，Bitwarden 的轻量版）。

> ⚠️ 这是高敏感服务：务必 HTTPS + 强主密码 + 2FA，并做好备份。一旦数据丢了，所有密码都没了。示例在 [`examples/docker-compose/vaultwarden/`](../../examples/docker-compose/vaultwarden/docker-compose.yml)。

## 安全别忘了

- 公网访问的服务都要 HTTPS + 强密码 + 2FA
- 分享链接设有效期和密码
- 镜像勤更新，见 [6.5 安全加固](../../docs/06-网络与远程访问/6.5-安全加固.md)

## 写在最后

Nextcloud 适合全面私有云，Immich 专注 AI 相册。按需求挑一个，别部署一堆用不上的。公网访问务必 HTTPS。

## 动手试试

1. 部署 Immich 或 Nextcloud 其一，测一次手机自动备份。
2. 给它配 HTTPS，确认浏览器显示安全锁。
