# 13.3 UPS + NUT：断电时让 NAS 优雅关机

> 📌 先读：[2.1 核心部件选型](../02-硬件选型/2.1-核心部件选型.md) · ⏱ 大约 15 分钟

## 为什么需要这个

UPS（不间断电源）不只是"多撑几分钟"。真正重要的是：**让 NAS 知道电快没了，然后自己安全关机。**

如果没有这条通信链路，停电时 NAS 会一直跑到电池耗尽、突然断电——结果可能是硬盘损坏、ZFS/RAID 池出问题、虚拟机状态损坏。

> 💡 社区文章反复强调：突然断电会中断写入、损坏虚拟机状态、甚至破坏存储池。配置 UPS 自动关机，是"花小钱保大险"的做法。见 [致谢](../../CREDITS.md)。

## 两部分：UPS 硬件 + NUT 软件

- **UPS 硬件**：选一台功率足够的（见下）
- **NUT（Network UPS Tools）**：让 NAS 通过 USB 读取 UPS 状态，电量低时触发关机

## UPS 怎么选

关键看两件事：

1. **功率（VA/W）够不够**：所有设备满载功耗乘 1.5 倍余量
2. **续航够不够 NUT 反应**：哪怕只撑 10～15 分钟，也足够触发优雅关机了

社区有一份 [UPS 选型参考](https://selfhosting.sh/hardware/ups-sizing-calculator/) 列出了常见机型在不同负载下的续航（数据为参考，价格波动大）：

| 机型 | 规格 | 85W 负载续航 | 200W 负载续航 |
| --- | --- | --- | --- |
| APC BE600M1 | 600VA/330W | 约 25 分钟 | 约 8 分钟 |
| CyberPower CP1000PFCLCD | 1000VA/600W | 约 45 分钟 | 约 18 分钟 |
| APC BR1500MS2 | 1500VA/900W | 60+ 分钟 | 约 25 分钟 |

> 💡 家庭 NAS（闲时 20～50W）其实不需要很大 UPS，600～1000VA 就够用。选购详见 [2.5 功耗噪音散热](../02-硬件选型/2.5-功耗噪音与散热.md)。

## NUT 配置思路

以 Linux 自装 NUT 为例（各 NAS 系统也有图形化设置）：

```bash
# 1. 用 nut-scanner 识别 UPS 驱动
nut-scanner -U

# 2. 配置 /etc/nut/ups.conf
[myups]
    driver = usbhid-ups
    port = auto

# 3. 设置关机阈值（电量低到 20% 触发）
# 具体参数见 upsmon.conf 的 LOWBATT / SHUTDOWNCMD
```

要点：

- 用 USB 数据线连接 UPS 和 NAS（不是只插电源线）
- 设置低电量阈值（常见 20%～30%）
- 配置关机命令 `SHUTDOWNCMD`
- **做一次真实的断电测试**，确认关机流程真的能触发

各平台：

| 平台 | 方式 |
| --- | --- |
| 群晖 / 威联通 | 控制面板里直接配置 UPS 支持，较简单 |
| TrueNAS | 系统设置 → UPS，内置 NUT |
| 自装 Linux | 手动装 NUT，见 [rhomelab 的配置指南](https://rhomelab.com/hardware/ups-sizing-and-nut-setup) |

> ⚠️ 如果多台设备共用一台 UPS，要让连着 USB 的那台做 NUT 主服务器（primary），其他做网络客户端。有篇[群晖/威联通的 UPS 自动关机指南](https://techfromalex.com/ups-auto-shutdown-synology-qnap-nut) 讲清了主客户端关系。

## 别忘了测试

> ⚠️ 配完不做测试 = 没配。拔掉 UPS 输入电源，模拟断电，确认：
>
> 1. NAS 能检测到"_on battery_"
> 2. 电量降到阈值时能触发关机
> 3. 关机过程数据正常落盘

社区文章都强调这一点——模拟断电测试是验证 UPS 方案的唯一方法。

## 写在最后

UPS + NUT = 停电时优雅关机。选够功率的 UPS、配好 NUT 阈值、做一次真实测试。这是数据保护里"花小钱保大险"的一环。

## 动手试试

1. 估算你所有设备的满载功耗，看看需要多大 UPS。
2. 如果你已有 UPS，做一次断电测试，验证自动关机是否触发。
