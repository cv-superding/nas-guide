# 0.3 术语表

## 本章目标

- 掌握 NAS 技术中最常见的中英文术语
- 在阅读后续章节时能快速查阅

> 术语首次出现在正文中时会给出对照，本表用于集中查阅。

## 基础概念

| 中文 | English | 说明 |
| --- | --- | --- |
| 网络附属存储 | NAS (Network Attached Storage) | 通过网络提供文件存储服务的专用设备或系统 |
| 网络 | LAN / WAN | 局域网 / 广域网（互联网） |
| 文件协议 | SMB / NFS / AFP | 不同系统间共享文件的"语言" |
| 共享文件夹 | Shared Folder | 通过网络暴露给客户端的目录 |
| 用户 / 用户组 | User / Group | 控制访问权限的身份单位 |
| 权限 | Permission / ACL | 决定谁能读、写、执行 |
| 网络时间协议 | NTP | 让设备时间保持准确 |

## 硬件与存储

| 中文 | English | 说明 |
| --- | --- | --- |
| 机械硬盘 | HDD | 容量大、便宜、有机械结构 |
| 固态硬盘 | SSD | 快、静音、价高 |
| 冗余磁盘阵列 | RAID | 用多块盘换取冗余或性能 |
| 存储池 | Storage Pool | 多块物理盘组成的逻辑存储单元 |
| 卷 / 数据集 | Volume / Dataset | 存储池上可挂载的逻辑空间 |
| 热备盘 | Hot Spare | 平时空闲、故障时自动顶替的盘 |
| 坏道 | Bad Sector | 磁盘上无法读写的区域 |
| S.M.A.R.T. | S.M.A.R.T. | 硬盘自我监测、分析与报告技术 |
| 通电时间 | Power-On Hours | 硬盘累计工作时长 |

## 文件系统与数据保护

| 中文 | English | 说明 |
| --- | --- | --- |
| 文件系统 | File System | 组织和管理磁盘数据的方式 |
| 快照 | Snapshot | 某一时刻数据的只读影像，可快速回滚 |
| 校验和 | Checksum | 用于检测数据是否损坏的指纹 |
| 数据 scrub | Scrub | 主动扫描并修复潜在损坏 |
| 写时复制 | CoW (Copy-on-Write) | 修改数据时先写新位置，提升一致性 |
| 3-2-1 备份 | 3-2-1 Backup | 3 份数据、2 种介质、1 份异地 |

## 网络与访问

| 中文 | English | 说明 |
| --- | --- | --- |
| IP 地址 | IP Address | 设备在网络中的"门牌号" |
| 域名 | Domain | 便于记忆的地址，如 example.com |
| 动态域名 | DDNS | 把变化的公网 IP 绑定到固定域名 |
| 内网穿透 | NAT Traversal | 无公网 IP 时从外网访问内网设备 |
| 端口转发 | Port Forwarding | 把路由器端口映射到内网设备 |
| 反向代理 | Reverse Proxy | 统一入口，按路径分发到不同服务 |
| 虚拟专用网 | VPN | 加密的远程接入通道 |
| 传输层安全 | TLS / HTTPS | 加密网页传输的协议 |
| 网关 | Gateway | 连接不同网络的设备 |

## 容器与应用

| 中文 | English | 说明 |
| --- | --- | --- |
| 容器 | Container | 轻量的应用运行环境 |
| Docker | Docker | 最流行的容器平台 |
| 镜像 | Image | 容器的只读模板 |
| 编排 | Compose / Orchestration | 用配置文件定义和管理多个容器 |
| 虚拟机 | VM (Virtual Machine) | 模拟完整硬件的隔离环境 |
| 根权限 | Root / Privileged | 最高系统权限，慎用 |
| 自动化运维 | Ansible | 用代码定义并执行配置任务 |

## 小结

术语不必一次记全。遇到不认识的词，回到本表查阅即可。
