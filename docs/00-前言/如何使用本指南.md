# 这本书怎么用

先说结论：**别从头硬读。** 这本书是给你"查"和"挑"的，不是给你啃的。

## 先问自己一个问题

> 你最想解决的那件事，是什么？

把答案写下来，哪怕就一句"我怕孩子照片丢了"。这句话就是你这本书的导航仪。后面所有选择——买什么硬件、装什么系统、先读哪一章——都围着它转。

## 三条路，挑一条走

### 🟢 新手线：从零开始，稳稳当当

适合：还没买设备，或者设备刚到手还在吃灰。

```
01 认识 → 02 挑硬件 → 03 选系统 → 04 装起来 → 05 护数据
```

这条路我们陪你走完整全过程。读完你会拥有一台真正能用的 NAS，而不是一堆看不懂的配置。

### 🔵 进阶线：机器在，想住得更舒服

适合：系统已经装好，能存能取，但总觉得哪里不太对——比如外网访问没弄好、备份只有一份、服务越装越乱。

```
05 护数据 → 06 连通外网 → 07 装应用 → 08 变省心
```

### 🟠 场景线：我就想干成这一件事

适合：目标明确，比如"我要在家看 4K 原盘"或者"我要跑个自己的 AI"。

```
09 实战案例 → 缺什么回查什么
```

## 每章长什么样

为了让你不迷路，我们给每章安排了差不多的骨架，但尽量写得不像模板：

- **开头一个小场景**——先让你对上号，"对，我也是这种情况"
- **这章你能收获啥**——清楚列出学完能干什么
- **正文**——先讲道理，再教操作，最后告诉你怎么验证
- **来自社区的经验**——标注来源的真实踩坑小故事
- **一张图**——流程图、示意图或手绘配图，帮你在脑子里建立画面
- **结尾的小练习**——不是考试，是让你动手确认"我真会了"

## 你的设备不在书里怎么办

我们重点讲了六种平台，但 NAS 的世界远不止这些。如果你用的是群晖之外的 Unraid、OpenMediaVault，或者某个小众 ARM 板子：

1. 先读"讲道理"的章节——1.1、5.1、5.2、6.2 这些，原理是通用的。
2. 在平台对比表里找个最接近的当参照。
3. 提个 Issue 告诉我们，能补我们就补。

## 一个小建议

搭 NAS 最容易犯的错，是一开始就想把所有功能都塞进去。

**先让它做对一件事**——比如把照片备份好。等这件事稳了，再往上加影音、加 Docker、加 AI。每一步都验证过，睡得着觉。

> 我们见过太多"装了一堆服务最后全吃灰"的机器。慢即是快。
