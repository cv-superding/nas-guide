# 0.2 如何使用本指南

## 本章目标

- 根据自身的知识水平与目标，选择高效的阅读方式
- 理解"章节 + 示例 + 练习"三位一体的学习方法
- 学会使用配套资源加速实践

## 三条阅读路径

### 🟢 新手线：零基础起步

适合：还没买设备、对 NAS 概念不熟悉的人。

```
01 认识 NAS → 02 硬件选型 → 03 平台横评 → 04 第一次搭建 → 05 存储与数据保护
```

这条线从"是什么"讲到"装好并保护好数据"，读完你应该能独立完成一台可用 NAS 的搭建。

### 🔵 进阶线：已有 NAS，想深入

适合：已经装好系统，想提升数据安全、远程访问与应用能力的人。

```
05 存储与数据保护 → 06 网络与远程访问 → 07 应用服务 → 08 进阶主题
```

这条线偏重原理与方案对比，建议结合自己的设备边读边试。

### 🟠 场景线：带着目标来

适合：有明确需求，想直接看到成品的人。

```
09 实战案例（找到你的场景）→ 按需倒查相关章节
```

例如你想做家庭影音中心，就读 9.1，它会在关键步骤提示你回看 7.2（影音中心）与 6.2（远程访问）。

## 每章的固定结构

为了让你快速定位，每章（及多数小节）遵循统一结构：

1. **本章目标**：读完能做什么
2. **核心主题**：本章最重要的 3～5 个知识点
3. **正文**：概念 → 原理 → 操作 → 验证
4. **多平台差异**（如适用）：统一表格对比
5. **小结**：一句话总结
6. **练习**：动手或思考题

## 设备上没有的章节怎么办

本指南覆盖多个平台，但你的设备可能不在其中（例如 UnRAID、OpenMediaVault）。这时：

1. 优先读"概念型"小节（如 1.1、5.1、5.2、6.2），原理是通用的。
2. 在平台对比表中找到最接近的平台作为参照。
3. 欢迎通过 [Issue](https://github.com/cv-superding/nas-guide/issues) 提出补充需求。

## 小结

不要试图记住所有内容。带着问题读，边读边做，遇到问题回查，是效率最高的方式。
