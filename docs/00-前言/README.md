# 写在前面

这份指南是给谁写的？给你——一个可能连 RAID 是什么都还不确定，却已经动了"我也想搞一台 NAS"念头的人。

## 为什么会有这本指南

说个真实的小场景。

朋友老周有天半夜发消息给我："手机又提示存储满了，我把孩子的视频删了又后悔，你说我该怎么办？" 我回他："买台 NAS 吧。" 他问："NAS 是啥？贵不贵？麻烦吗？会不会我折腾半天最后吃灰？"

这串问题，我后来被问了不下二十遍。它们其实指向同一件事：**大家想把数据的掌控权拿回来，但中间隔着一堆听不懂的词和理不清的步骤。**

网上不是没有好资料。恰恰相反，好东西太多了——官方手册厚得像砖，论坛帖子藏着宝贝，UP 主讲得眉飞色舞。可问题是，它们都是"一块一块"的。新手站在中间，不知道该先拼哪块。

所以就有了这本书。它做的是一件事：**把碎片拼成一条路。**

> 我们不会一上来就塞给你"ZFS 写时复制"这种词。先让你这台机器跑起来，等你需要懂的时候，再回头讲。

## 这本书想陪你走的路

```mermaid
flowchart LR
    A[认识它] --> B[挑硬件] --> C[选系统] --> D[装起来] --> E[护好数据] --> F[玩花样]
```

从"这东西是啥"一路到"我能用它跑 AI"。每一步都回答三个问题：**这是什么、为什么这么做、做完了怎么确认对**。

## 我们约定几件事

- **不吓唬人。** 不用"不这么做数据全丢"这种话制造焦虑，但真有风险时会明确告诉你。
- **不故作高深。** 术语第一次出现会说人话，实在绕不开就给个比喻。
- **不替你做决定。** 每个平台都有适合的场景，我们摆事实，你来做选择。
- **不提供下载。** 软件请去官方渠道，这是底线，也是对作者和用户的尊重。
