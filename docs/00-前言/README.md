# 00 前言 · 写在前面

## 本章目标

- 理解这套指南的设计思路与适用对象
- 知道如何在三条阅读路径中选择适合自己的路线
- 建立对全书术语与约定格式的基本认识

## 为什么需要一本"系统"的 NAS 指南

搜索"NAS 教程"，你会得到大量结果：某个品牌的安装视频、某篇 Docker 部署文章、某个论坛的攒机帖。它们单独看都有价值，但拼不起来——因为缺少一条主线告诉你：

- 先学什么、后学什么？
- 哪些是通用原理，哪些只是某个平台的按钮位置？
- 我这种需求（例如"只想备份照片"）到底该走到哪一步为止？

本指南试图补上这条主线。我们把内容拆成"概念 → 选型 → 搭建 → 数据 → 网络 → 应用 → 进阶 → 案例"的递进结构，并在每一层都提供多平台对比，让你既能理解原理，也能落到具体设备。

## 本指南不做什么

> ⚠️ 本指南**不提供任何软件下载、破解资源或镜像**，也不推荐任何"一键成品盘"。所有工具请从官方渠道获取。

- 不代替官方文档：具体版本的按钮位置和参数可能变化，遇到差异请以官方文档为准。
- 不承诺绝对安全：任何存储与网络配置都有风险，请自行评估并做好备份。
- 不站队品牌：每个平台都有适用场景，我们尽量客观呈现差异。

## 练习

2. 根据目标，在 README 的三条路径中圈出你打算走的路线。
