# 新人避坑指南：前人踩过的坑，你绕着走

这一页收集了新手最常踩的坑。不是吓唬你，是希望你少走点弯路。

每条都写着"为什么会踩"和"怎么避开"，看完再去动手，心里踏实很多。

## 硬件篇

### 坑 1：CPU 买太猛，硬盘买太差

**为什么踩**：跑分看着爽，觉得"性能越好越保值"。

**真相**：NAS 里硬盘才是主角。i9 配三块-desktop 盘，数据照样不安稳。

**怎么避**：钱优先花在 NAS 专用盘和内存上，CPU 够用就行。见 [2.1](../../docs/02-硬件选型/2.1-核心部件选型.md)、[2.2](../../docs/02-硬件选型/2.2-硬盘选型.md)。

### 坑 2：买了 SMR 盘做 RAID

**为什么踩**：只看容量和价格，没看记录方式。

**真相**：SMR 盘在 RAID 重建时慢到崩溃，甚至失败。

**怎么避**：买盘前搜"型号 + CMR"，确认是 CMR 再下单。见 [2.2](../../docs/02-硬件选型/2.2-硬盘选型.md)。

### 坑 3：电源和散热凑合

**为什么踩**：觉得"不就是几块盘嘛"。

**真相**：多盘启动瞬间电流很大，劣质电源可能直接烧盘；散热差会缩短硬盘寿命。

**怎么避**：靠谱电源 + 硬盘架减震 + 注意风道。见 [2.5](../../docs/02-硬件选型/2.5-功耗噪音与散热.md)。

## 安装篇

### 坑 4：没备份就格式化

**为什么踩**：急着装系统，觉得"新盘应该没东西"。

**真相**：选错盘、或者盘里有旧数据，格式化后基本救不回来。

**怎么避**：装之前把目标盘的数据备份到别处，**并验证能读出来**。见 [4.1](../../docs/04-第一次搭建/4.1-安装前准备.md)。

### 坑 5：笔记本合盖就休眠

**为什么踩**：拿旧笔记本当 NAS，没改电源设置。

**真相**：默认设置下合盖就睡，NAS 一睡等于"失联"，手机备份全断。这是真实用户踩过的坑（[数巢笔记的实测](https://www.shunot.com/nas/1000.html)）。

**怎么避**：关掉合盖休眠，设为"接通电源时不休眠"。见 [3.7](../../docs/03-平台横评与选型/3.7-树莓派与软路由.md)。

## 数据篇

### 坑 6：以为 RAID = 备份

**为什么踩**："我做了 RAID，坏一块盘没事，数据安全了。"

**真相**：RAID 防误删、防勒索、防火灾吗？都不防。见 [5.4](../../docs/05-存储与数据保护/5.4-备份3-2-1原则.md)。

**怎么避**：RAID + 快照 + 异地备份，三样都要。

### 坑 7：把同步当备份

**为什么踩**：开了云盘同步，觉得"两边都有，丢不了"。

**真相**：你删一份，另一份也删；勒索加密，两边一起加密。

**怎么避**：同步管"一致"，备份管"能回到过去"。见 [5.4](../../docs/05-存储与数据保护/5.4-备份3-2-1原则.md)。

### 坑 8：备份从来不验证

**为什么踩**：设置完定时任务就再没看过。

**真相**：备份可能早就在某个环节失败了，你却以为万事大吉。

**怎么避**：定期做恢复演练——哪怕只恢复一个文件。见 [5.4](../../docs/05-存储与数据保护/5.4-备份3-2-1原则.md)。

## 网络与安全篇

### 坑 9：管理界面直接暴露公网

**为什么踩**：图方便，路由器上做了端口转发。

**真相**：这是家庭 NAS 被攻击的头号原因。

**怎么避**：用 VPN（Tailscale）访问，别直接暴露。见 [6.2](../../docs/06-网络与远程访问/6.2-远程访问方案对比.md)、[6.5](../../docs/06-网络与远程访问/6.5-安全加固.md)。

### 坑 10：密码太简单 / 一直用默认

**为什么踩**："家里设备，谁会黑我。"

**真相**：公网扫描器 24 小时不停。

**怎么避**：强密码 + 2FA + 关掉默认管理员账号。见 [6.5](../../docs/06-网络与远程访问/6.5-安全加固.md)。

## Docker 篇

### 坑 11：容器数据没映射出来

**为什么踩**：照着教程跑起来就不管了。

**真相**：删容器或升级镜像时，数据跟着没了。

**怎么避**：所有要保留的数据都用 `volumes` 映射到 NAS 目录。见 [7.1](../../docs/07-应用服务/7.1-Docker基础.md)。

### 坑 12：一口气装二十个服务

**为什么踩**："反正免费，都装上试试。"

**真相**：资源占用、安全面、维护成本全上去了，最后在用的没几个。

**怎么避**：一次装一个，确认真的用得上再装下一个。见 [07 章概览](../../docs/07-应用服务/README.md)。

## 心态篇

最后一个"坑"，不算技术坑，但最致命：

> **想一步到位，结果卡住放弃。**

见过太多人一开始就规划 All in One、万兆、全闪、自动化全家桶，结果在某个配置环节卡了三天，机器就此吃灰。

**慢即是快。** 先让 NAS 做对一件事——比如把照片备份好。等这件事稳了，再往下走。
