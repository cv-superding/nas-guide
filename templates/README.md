# 写作模板 templates/

本目录提供统一的内容模板，帮助贡献者保持风格一致。

## 模板列表

| 模板 | 用途 |
| --- | --- |
| [chapter-template.md](chapter-template.md) | 章节/小节通用模板 |
| [platform-template.md](platform-template.md) | 平台介绍模板 |
| [case-template.md](case-template.md) | 实战案例模板 |

## 为什么需要模板

统一的 Structure 让读者知道"在哪里找什么"，也让贡献者不必从空白页开始。每篇内容都包含：目标 → 主题 → 正文 → 平台差异（如适用）→ 小结 → 练习。

写作前请先阅读 [CONTRIBUTING.md](../CONTRIBUTING.md)。
