# 练习：读完就上手，别只看不练

看教程最容易产生一种错觉——"我懂了"。

但真正懂没懂，得看你能不能做出来。这个目录就是给你"做一遍"用的。

## 怎么用

- 每读完一章，打开对应的练习文件
- 动手类练习建议在真实设备或测试环境里做
- 思考题没有标准答案，重要的是你想过
- 进度表复制到你自己的笔记里，完成一个勾一个

> 💡 卡住了别硬扛。回去翻对应章节，或者去 [FAQ](../docs/附录/B-常见问题FAQ.md) 找找。

## 一句提醒

不用追求"全做对"。做错了、卡住了，往往比一路顺畅学到的更多——前提是你把过程记下来了，方便回头复盘。
